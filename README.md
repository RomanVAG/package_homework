#
# Проект homework_11_2

## Описание:

Это домашняя работа на Python, направленная на закрепление изученного материала. 
Проект содержит три основные функции:

## Модуль `mask`

### Функция `get_mask_card_number`
- **Тестирование маскирования номера карты**:
  - Проверка правильности маскирования для стандартных номеров карт (16 цифр)
  - Тестирование граничных случаев:
    - Номера карт нестандартной длины (меньше/больше 16 цифр)
    - Частично заполненные номера карт
  - Проверка обработки пустых строк и строк без номера карты
  - Валидация формата вывода (XXXX XX** **** XXXX)

### Функция `get_mask_account`
- **Тестирование маскирования номера счета**:
  - Проверка правильности маскирования для стандартных номеров счетов (20 цифр)
  - Тестирование нестандартных случаев:
    - Номера счетов сокращенной длины
    - Пограничные значения длины номера
  - Проверка обработки некорректных входных данных
  - Валидация формата вывода (**XXXX**)

## Модуль `widget`

### Функция `mask_account_card`
- **Тестирование автоматического определения типа данных**:
  - Параметризованные тесты с различными типами карт (Visa, Mastercard, МИР)
  - Тесты с разными форматами счетов
  - Проверка правильности выбора маски (карта или счет)
- **Тестирование обработки ошибок**:
  - Некорректные форматы данных
  - Неполные данные
  - Пустые строки
  - Смешанные форматы

### Функция `get_date`
- **Тестирование преобразования дат**:
  - Проверка корректности форматирования ISO-даты в человекочитаемый формат
  - Тестирование различных форматов входных дат:
    - Полный ISO-формат
    - Дата без времени
    - Альтернативные форматы дат
  - Проверка обработки:
    - Пустых строк
    - Некорректных форматов даты
    - Отсутствующей даты

## Модуль `processing`

### Функция `filter_by_state`
- **Тестирование фильтрации по статусу**:
  - Проверка фильтрации для всех возможных статусов (EXECUTED, CANCELED, PENDING)
  - Тестирование пустого списка транзакций
  - Проверка работы со списком без элементов с искомым статусом
  - Параметризованные тесты для разных комбинаций статусов
  - Проверка значения по умолчанию (EXECUTED)

### Функция `sort_by_date`
- **Тестирование сортировки по дате**:
  - Проверка сортировки по убыванию (новые -> старые)
  - Проверка сортировки по возрастанию (старые -> новые)
  - Тестирование с одинаковыми датами
  - Проверка обработки:
    - Пустого списка
    - Списка с одним элементом
    - Некорректных форматов даты
  - Проверка устойчивости к отсутствию поля даты

## Модуль `generators`

### Функция `filter_by_currency`
- **Фильтрует список транзакций, возвращая только те, которые проведены в указанной 
валюте (например, USD).**

### Функция `transaction_descriptions`
- **Извлекает описания операции по очереди из списка словарей с транзакциями.**

### Функция `card_number_generator`
- **Генерирует номера банковских карт в формате XXXX XXXX XXXX XXXX в заданном
диапазоне от 0000 0000 0000 0001 до 9999 9999 9999 9999.**

## Модуль `decorators`

### Декоратор `log`
- **Декоратор @log предназначен для автоматического логирования выполнения функций. 
Он записывает в лог информацию о начале и завершении выполнения функции, а также о возникших ошибках.**
### Особенности:
- Логирование начала выполнения - с временной меткой и аргументами
- Логирование успешного завершения - с результатом и временем выполнения
- Логирование ошибок - с типом исключения и входными параметрами
- Гибкий вывод - в файл или консоль
- Защита от рекурсивного логирования - предотвращение дублирования логов
- Потокобезопасность - корректная работа в многопоточной среде

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:RomanVAG/package_homework.git
```
2. Установите зависимости:
```
poetry install
```


## Использование
Добавьте в ваш проект функции из файлов src/processing.py, src/widget.py, src/mask.py, src/generators.py

Пример работы функции содержится в файле main.py

Тесты работы функций содержится в файлах tests/test_processing.py, tests/test_widget.py, tests/test_mask.py, 
tests/test_generators.py
